요약

검수된 4000장 데이터와 대량 22000장 데이터를 3클래스(head, helmet, vest) YOLO 형식으로 통합하고, YOLO11n으로 학습한 뒤 Raspberry Pi 5에서 OpenCV와 웹 스트리밍을 이용해 안전모/조끼 착용 여부를 실시간 및 배치 방식으로 판단하는 시스템입니다.

데이터 구성	

YOLO Dataset Format	검수된 4000장 데이터와 추가 22000장 데이터를 합쳐 학습용 데이터셋 구성

검수 데이터	

직접 라벨 확인	4000 데이터는 눈으로 직접 확인한 신뢰도 높은 데이터로 사용

데이터 분할	
Train / Valid Split	4000 데이터 중 2800장은 train, 1200장은 valid로 사용

추가 데이터	
22000 Dataset	22000 데이터는 train 데이터에 추가하여 학습량 확보

라벨 통합
3-Class Label	최종 라벨을 head, helmet, vest 3개로 통일

라벨 변환	
Class Mapping	22000의 helmet, vest는 유지, 기존 head는 삭제, person은 head로 변환

학습 모델	
YOLO11n	가볍고 빠른 nano 모델을 사용하여 라즈베리파이 구동에 적합하게 학습

학습 환경	
Google Colab GPU 환경에서 YOLO11n 모델 학습 진행

학습 결과	
best.pt	학습 완료 후 최적 가중치 best.pt를 라즈베리파이에 배포

실시간 처리	
OpenCV	카메라 프레임을 읽고 객체 감지 결과를 화면에 표시

객체 감지	
Ultralytics YOLO 사람, 안전모, 안전조끼를 감지하여 착용 여부 판단

판단 로직	
Person-PPE Matching	사람 박스 안에 helmet, vest가 있는지 확인해 SAFE, NO HELMET, NO VEST 판단

웹 출력	
Python HTTP Server	라즈베리파이에서 웹 서버를 실행해 PC 브라우저로 결과 확인

배치 검증	
HTML Review	여러 이미지를 자동 분석하고 결과를 index.html로 정리

성능 확인	
FPS / 처리 시간	실시간 화면에는 FPS, 배치 결과에는 이미지별 처리 시간을 표시
